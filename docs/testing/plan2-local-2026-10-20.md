## Regression baru dan perbaikan

| Area | Bukti/perilaku |
|---|---|
| Modal | 50 transfer serentak tidak membuat cadangan negatif; rollback tidak menyisakan kredit; request ulang tidak mengulang transfer |
| PostgreSQL | 40 transfer serentak, 20 sukses, total 1.000 tetap; journal/idempotency/reload konsisten |
| Ownership | Dua instance pada ETH dan dua binding dalam satu instance; flatten satu pemilik tidak menjual ETH pemilik lain |
| Reservasi | Buy plus buffer, sell hanya milik sendiri, dua OCO leg mengunci sekali; partial kedua menjaga rasio reservasi |
| Fee | Base fee mengurangi coin yang diterima; BNB raw debit dipertahankan dan dibebankan setelah harga tersedia |
| Recovery Spot | ID trade/komisi asli dari myTrades; prefix partial dilewati, identitas salah atau split trade ditolak |
| Terminal event | Cancel dengan cumulative fill yang belum dibukukan mempertahankan reservasi; event NEW tidak membuka terminal order lagi |
| Crash | DB outage setelah financial fill sebelum event checkpoint; restart memutar durable inbox tanpa debit ganda |
| Proteksi | Checkpoint pending entry memulihkan SL/TP/trailing; orphan directional inventory diarahkan ke fallback exit |
| Sim | Settlement per fill mencegah stop dan target menjual dua kali pada candle yang menyentuh keduanya; candle 4h tidak dipakai mencocokkan fill |
| Risiko | Banyak order kecil tidak melewati cap simbol parent; transfer bukan profit; halt tetap sticky setelah harga/dana pulih |
| Lifecycle | Clone tidak menyalin modal/posisi; binding baru/edit tidak resume/reset dengan engine lama; arsip tidak mengunci tunai |
| Feed | Entry dengan harga lebih dari dua menit ditahan; warmup tidak mengirim order; reconnect meminta reconciliation |
| HTTP | Basic Auth, CSRF, CSP tanpa unsafe-inline, escaping XSS; decoder menolak field asing/trailing JSON |
| CSV | OHLC invalid, duplicate timestamp dan gap ditolak; candle strategi parsial tidak membuat sinyal |

Temuan saat fixing: checkpoint nil (`null`), harga engine belum di-prime pada
restart, risiko cancel-before-fill, resume konfigurasi engine lama, reservasi
partial yang terlalu cepat berkurang, stale DCA timer entry, replay OHLC 4h,
dua leg Sim sebelum cancel diproses, dan penyalinan state JSON penuh yang
memperlambat backtest. Sudah diperbaiki dan pengujian relevan dijalankan ulang.
